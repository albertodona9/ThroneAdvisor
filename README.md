# Toilet Ranking Web App

This is a simple web application for ranking toilets.

## Project Structure

*   `index.html`: The main entry point of the application.
*   `ranking.html`: The page to display toilet rankings.
*   `style.css`: The stylesheet for the application.
*   `main.js`: The main JavaScript file for the application.
*   `server.py`: A Python backend server.
*   `toilets.db`: A SQLite database to store toilet data.

## How to run

1.  Start the Python backend server: `python server.py`
2.  Open `index.html` in your browser.
